# Public cable extension registry provenance

This directory defines the public synthetic-only v1 registry embedded by `musubi-cable-sim`.
It records the cumulative T0 motor-torque, T1 scalar/single-end tension, and T2 both-end vector
tension plus geometry/shape-proxy vocabulary. `confirmed_*` labels are fixture ground truth only;
unconfirmed cause candidates use separate label names.

It contains no partner, client, field, or proprietary data. Unknown semantic identifiers remain
preserved sidecar records in the general extension contract, while the committed generator fails
closed if it emits one. Inclusion here only fixes public value kinds, units, label spelling, and
synthetic provenance; it is not a performance claim or runtime-load approval.
